# NSHruno

A Bruno-like API client, built with [Native Shell (NSH)](https://nsh.dev) — one
app rendered through each platform's own views on a shared Rust engine. UI is
written in TSX running on QuickJS; no DOM, no npm.

App manifest (`nsh.json`): `Bruno-mygo` / `com.example.brunomygo`.

## Requirements

- [NSH CLI](https://nsh.dev) — `nsh --version`
- TypeScript is resolved through `.nsh/tsconfig.json` (generated by `nsh check`)

## Commands

```sh
nsh check   # type-check TSX (tsc against .nsh/types)
nsh build   # bundle; reports errors nsh check can't see
nsh test    # run *.test.tsx headless
nsh run     # launch the app (--target ios | android | web | macos | linux | windows)
```

## Structure

| File           | Purpose                                  |
| -------------- | ---------------------------------------- |
| `nsh.json`     | App manifest (name, id, version, build)  |
| `App.tsx`      | Root component, `mount(App)` entry       |
| `App.test.tsx` | Headless UI test (`nsh/test`)            |
| `tsconfig.json`| Extends generated `.nsh` config          |

## Notes

- TSX is not the web: no DOM, no Node, no npm UI packages. Standard modules
  are limited to `buffer`, `console`, `crypto`, `fs/promises`, `net`, `os`,
  `path`, `process`, `url`, `websocket`, `zlib`.
- Style with semantic theme tokens (`bg-background`, `text-foreground`,
  `bg-primary`), not raw colors.
